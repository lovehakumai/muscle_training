# 課題：README.md

今回選んだテーマ: **2. pandasでの結合（mergeにおける重複・欠損パターンへの対応）**

### シナリオ:
本番のデータパイプラインにおいて、トランザクションデータ（日次売上など）とマスタデータ（商品情報など）を結合する際、マスタデータの重複や一部キーの欠損（不整合）によって、結合後に意図せず行数が膨れ上がったり（多対多の爆発）、データが不意に消失したりする問題が頻発します。安全にデータを統合するための前処理と検証コードを実装します。

### 制約条件:
- 重複するマスタデータを事前に適切にクレンジングすること。
- 意図しない「多対多（Many-to-Many）」の結合爆発を防ぐための検証プロセスを入れること。

### 準備するもの:
以下のサンプルコードをベースに、スクリプトを実装してください。
```python
import pandas as pd

# ----------------------------------------------------
# Sales transaction data (Target to keep original row count)
# ----------------------------------------------------
df_sales = pd.DataFrame({
    "transaction_id": [1, 2, 3, 4, 5],
    "product_id": [101, 102, 101, 999, 102], # '999' is an invalid product_id missing in master
    "amount": [1200, 1500, 800, 300, 2000]
})

# ----------------------------------------------------
# Product master data (Contains a duplicate entry due to system bug)
# ----------------------------------------------------
df_products = pd.DataFrame({
    "product_id": [101, 102, 103, 101], # '101' is duplicated
    "category": ["Electronics", "Furniture", "Apparel", "Electronics_New"]
})
```

### 期待するスクリプトの条件:
1. `df_products` に含まれる `product_id` の重複を事前に排除してください（最後のレコード `Electronics_New` を残すように制御してください）。
2. `df_sales` をベースに、クレンジング後の `df_products` を左結合（Left Join）してください。その際、結合が「多対一（many_to_one）」または「一対一（one_to_one）」の関係を満たしていることを、`pandas.merge` の検証引数などを用いて保証してください。
3. マスタデータに存在しない `product_id` （例：`999`）のカテゴリについて、欠損値（NaN）を `"Unknown"` という文字列で適切に補完してください。
4. 最終的にクレンジング・結合が完了した DataFrame を出力してください。また、結合によって元の `df_sales` の行数が変わっていないことを検証する簡単なアサーション（assert）を記述してください。
